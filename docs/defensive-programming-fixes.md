# 防御性编程审计修复

基于 `a25a3bd` 的审计，本轮处理“默认成成功”、过度兼容和重复检查。原作与 `web/` 历史原型未改。

## 行为修复

- HTTP 成功响应必须符合当前协议。缺少 user/profile、损坏档案、缺少 draw reward 均报格式错误；只有明确 `{user:null}` 的查询/退出响应才能清除会话。
- 新建档案、旧数据迁移、当前数据解析分为 `createProfile`、`migrateLegacyProfile`、`parseProfile`。迁移丢弃不合法历史会报告数量；当前档案损坏不会被改成空档案。
- `BattleRecord`、`DrawRecord`、`DrawReward` 与 API action/result 类型贯穿组件。删除组件内 object/numeric 修复，奖励和战绩不再生成默认名称、1-1 失利或假到账。
- 小队列表缺字段不再补任务/人数；请求失败显示失败/旧结果状态，停用过期列表上的加入按钮，后续正常请求清除状态。
- WebSocket 已知消息集中解析；格式损坏关闭无效会话并明确提示，未知扩展可忽略。保留重连和主动关闭逻辑，不吞内部回调异常。
- 删除游客旧 upgrades 入口及共享规则的旧三项数值升级；正式技能树、装备、弹种继续生效。
- 默认只服务 `client/dist`。缺少构建时网页返回清楚的503提示，API-only开发仍可用；旧界面必须显式指定 `webRoot` 或 `DAWN_CLIENT_DIR`。
- 奖励缺少账户、角色或必要关卡上下文会抛内部错误，不能标为已保存。保留逐玩家重试与数据库唯一账本。
- HTTP业务拒绝为400；内部/SQLite/当前档案格式故障记日志并返回通用500，事务失败不扣款。

## 内部精简

- 地图形状与规则检查合并，删除已解析数组/对象上的重复判断；JSON入口校验一次。Game接收内部GameMap并深拷贝，保持地图所有权，不再反复遍历校验。
- 删除静态Equipment导入的不可能回退、旧Player.upgrades及已初始化字段上的默认值；effectConfig不再反复检查string[]。
- 历史奖励解析验证数据格式，不用现在的补偿金额或稀有度公式反查旧记录，避免正常平衡调整使历史档案失效。
- 迁移仅捕获预期的数据错误，内部编程错误继续暴露，不作为“坏记录”吞掉。

没有引入新的运行时校验框架。必要校验留在HTTP、WebSocket和存档读入边界；组件与模拟内部依赖明确类型。

## 保留的保护

身份、请求大小和枚举、余额与持有检查、事务回滚、持久化奖励防重、房主/准备权限、断线状态、异步卸载保护，以及WebGL/Audio能力降级。边界碰撞、生命和冷却判断仍属于玩法。

## 验证

- `npm run build`：共享编译、客户端严格类型检查、生产构建通过。
- `npm test`：103 项测试通过，0 失败。
- 新增客户端协议测试直接执行TypeScript源码，通过Node原生类型剥离及仅用于测试的模块解析配置；没有手写转译器或将JS编译文件写回源目录。
- 回归覆盖：畸形200、损坏档案、空奖励、伪造列表字段、已知坏消息关闭、未知扩展、真实房间协议、匿名旧升级、缺构建、账户/角色缺失、500回滚和旧历史迁移报告。
- 真实网络测试使用当前RoomClient与当前服务器，走过入房、Boss开局与双方暂停；未访问或修改玩家个人档案。
- 本地已有SQLite档案只读检查，未写入玩家记录。正常战斗与保留保护沿用回归测试验证。

此修复未重做视觉、调整正式技能数值或执行公网部署。移除的旧flat upgrades是已退出产品设计的兼容入口。
