# 黎明之战 · Battle for the Dawn

原作：**闫鑫、方铮辉**。2017 年的 EVA 致敬机甲项目，继续在原仓库开发。

当前为 **v0.3.1 EVA 养成版**：四类机体、独立成员培养、双人合作与 MAGI 演习。任何玩家都可以创建档案和组队。原始 `NewTank/`、`Chartlet/` 保留不动；`web/` 保留原型和素材，正式客户端位于 `client/`。

## 本地运行

需要 Node.js 22.13 或更高版本（本次在 22.22.3 验证）。

```sh
npm ci --ignore-scripts
npm run build
npm start
```

打开 **http://127.0.0.1:8178**。封面点击或滑动进入登录 / 注册；个人练习也可暂不登录。Mac / Windows 可在完成依赖安装后使用仓库中的启动脚本。

开发时分开启动：

```sh
npm run build:shared
npm run dev:server
# 另一个终端
npm run dev
```

开发客户端在 `http://127.0.0.1:5173`，API 和 WebSocket 代理到 8178。修改共享规则后重新 `build:shared` 并重启服务端；前端由 Vite 更新。

`127.0.0.1` 仅指本机。已部署至实验蜂主机：http://8.130.114.41/dawn/ 。两位玩家访问同一站点并注册即可组队；本机试玩账号未迁移。部署记录见 [实验蜂部署](docs/deployment-shiyanfeng.md)。见 [联网与部署说明](docs/multiplayer.md)。

## Docker 运行

已有 Docker Engine、Compose 和 Buildx 插件时，在仓库根目录执行：

```sh
docker compose up -d --build --wait
```

默认地址仍为 `http://127.0.0.1:8178`。账号保存在独立命名卷中，重建容器保留存档；新卷初次启动需要注册账号。若原 Node 版本已占用端口，使用 `DAWN_HTTP_PORT=8188 docker compose up -d --build --wait`。环境变量、现有存档导入、备份和更新流程见 [Docker 手册](docs/docker.md)。

## 当前结构

| 目录 | 用途 |
| --- | --- |
| `client/src/game/` | Phaser Boot、背景、战斗场景，摄像机、精灵、输入、特效 |
| `client/src/ui/` | React 登录、技能树、配件、补给、HUD、看板适配 |
| `client/src/services/` | 账户 API、房间协议、音频 |
| `packages/simulation/src/` | 严格 TypeScript 共享规则与域类型，不依赖浏览器或 Phaser |
| `server/` | Node.js 房间服务与 SQLite 个人档案 |
| `web/assets/` | 原作素材副本与新增图像；构建时复制到客户端 |
| `web/` | 上一版原型与回归测试，不再作为新客户端入口 |
| `data/` | 本地个人档案，Git 忽略，不应上传 |

## 已接入的流程

- 固定 1600×900 舞台；封面、登录、机库、研究、整备、战前准备、战斗和复盘。
- 4 台机体、4 名驾驶员、3 名支援成员，48 种基础编组；同驾驶员组队仍使用各自配置与库存。
- 永久研究、免费预设、两条特殊路线、三级经费整备；机体、成员、类型熟练度、共鸣和有限精通分别生效。
- 3 种主武器、2 种近战、9 件普通装备与 4 件精通装备；两类特殊弹和两个消耗品携行位，标准射击持续可用。
- 作战经费与特务配额分账；七类普通补给、联合保底、重复调拨、数量库存、持久损伤和自动整备。
- 三阶段合作 Boss、交叉火力、屏障掩护、部位破坏；十二关及独立突袭、护送、防守、供能实验任务。
- MAGI 可试用已上线未拥有内容，固定条件比较两套配置，使用模拟队友或双人演习，并复习战绩阶段；不影响真实养成和库存。
- 有效贡献结算、事件复盘、资历与档案；后勤整备试验使用临时基础机，只恢复少量经费。
- 单次兑换券、人工验款记录与特别支援许可；没有第三方支付渠道或现金价格。
- 服务端权威配置、短按输入确认、刷新重连、双方事务结算、检查点与中断恢复。数据库写入故障会暂停战斗，不能用暂停按钮绕过。

新账号获得二号机／明日香、零号机／绫波丽与美里。未击毁机体可以带伤出战；击毁机体需维修。已有档案更新前先按[维护说明](docs/eva-operations.md)预览迁移和备份。新房间要求协议 v3，旧页面请刷新。

## 操作

两位联网玩家均使用自己电脑的相同键位。

| 操作 | 按键 |
| --- | --- |
| 移动 | 方向键 |
| 主武器 | 空格 |
| 基础推进 / 修复 / 近战 | Q / E / F |
| 三个可配置战术槽 | W / R / C |
| 两个消耗品位 | Z / X |
| 切换弹种 | 1 / 2 / 3 |
| 选择 Boss 部位 | Tab 或 HUD 按钮 |
| 暂停 / 继续 | Esc |

弹種为游戏化设计：阳电子穿甲偏精确直击，N² 高爆偏范围，共振碎甲提供短时防护削弱。近战分刀刃扇形与长矛突刺。
