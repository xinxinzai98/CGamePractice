# 黎明之战 · Battle for the Dawn

原作：**闫鑫、方铮辉**。2017 年的 EVA 致敬机甲项目，继续在原仓库开发。

当前为 **v0.2 Phaser 迁移版**：Web 客户端 + 双人合作房间 + 个人练习。任何玩家都可以创建档案和组队。原始 `NewTank/`、`Chartlet/` 保留不动；`web/` 保留原型和素材，正式客户端位于 `client/`。

## 本地运行

需要 Node.js 22.13 或更高版本（本次在 22.22.3 验证）。

```sh
npm ci --ignore-scripts
npm run build
npm start
```

打开 **http://127.0.0.1:8178**。封面点击或滑动进入登录 / 注册；个人练习也可暂不登录。Mac / Windows 可在完成依赖安装后使用仓库中的启动脚本。

开发时分开启动：

```sh
npm run build:shared
npm run dev:server
# 另一个终端
npm run dev
```

开发客户端在 `http://127.0.0.1:5173`，API 和 WebSocket 代理到 8178。修改共享规则后重新 `build:shared` 并重启服务端；前端由 Vite 更新。

`127.0.0.1` 仅指本机。当前未做公网部署；以后部署到服务器时，两位玩家访问同一站点即可组队。见 [联网与部署说明](docs/multiplayer.md)。

## 当前结构

| 目录 | 用途 |
| --- | --- |
| `client/src/game/` | Phaser Boot、背景、战斗场景，摄像机、精灵、输入、特效 |
| `client/src/ui/` | React 登录、技能树、配件、补给、HUD、看板适配 |
| `client/src/services/` | 账户 API、房间协议、音频 |
| `packages/simulation/src/` | 严格 TypeScript 共享规则与域类型，不依赖浏览器或 Phaser |
| `server/` | Node.js 房间服务与 SQLite 个人档案 |
| `web/assets/` | 原作素材副本与新增图像；构建时复制到客户端 |
| `web/` | 上一版原型与回归测试，不再作为新客户端入口 |
| `data/` | 本地个人档案，Git 忽略，不应上传 |

## 已接入的流程

- 固定 1600×900 逻辑舞台，16:9 等比缩放与留边。
- 主视觉封面、登录 / 注册、真实资源加载反馈、机库大厅。
- 小队创建 / 加入 / 公开列表；联网必须登录，每个账号一个活跃席位。**进房后**选择任务、小关卡、难度、驾驶员与配置；按房主进度选关，改配装后重新准备。
- 两名机体的技能树、熟练度、装备、弹种与近战；免费补给。
- 原作教学与个人练习；十二关使用独立内容定义，前两关保留原作场地。
- 实际阻挡移动和弹体的合作闸门，四个 Boss 各三阶段；每阶段协作开盾，攻击预警使用实际弹道数据。
- 刷新页面后进入可恢复本人对局；短按技能及射击使用序号确认，音效通过独立战斗事件播放。
- 整局结算持久登记，两名玩家奖励一起提交；离房仍重试，已登记的结果可在重启后补发，重复请求不重复扣券或发奖。
- SQLite 版本迁移与升级前备份、经济操作流水；改密和受控离线恢复工具。

## 操作

两位联网玩家均使用自己电脑的相同键位。

| 操作 | 按键 |
| --- | --- |
| 移动 | 方向键 |
| 主武器 | 空格 |
| 推进 / 核心技能 / 修复 / 爆发 | Q / W / E / R |
| 近战 / 主动配件 | F / C |
| 切换 AP / HE / HESH 弹种 | 1 / 2 / 3 |
| 暂停 / 继续 | Esc |

弹種为游戏化设计：阳电子穿甲偏精确直击，N² 高爆偏范围，共振碎甲提供短时防护削弱。近战分刀刃扇形与长矛突刺。

## 验证与阶段边界

```sh
npm run build
npm test
```

构建包含共享规则编译、客户端严格类型检查和 Vite 生产包。测试覆盖规则、迁移一致性、多人房间、事务、迁移、故障回滚与重复奖励防护。

自动化验证增加了同账号重复占位、准备后改技能、半局结算回滚、离房补发、响应丢失重试、版本迁移、备份恢复和 80/150 ms 延迟联调。四场 Boss 已用正常双人控制输入完成通关回归，包含阶段变化和倒地救援。**这仍是待持续打磨的版本**，不代表十二关平衡性都经过人工通关验收。

看板目前为独立单图网格动画适配，不能等同于完整 Live2D 分层模型；音乐为合成配乐。专业角色动画、美术一致性和关卡节奏仍需后续制作与试玩。
